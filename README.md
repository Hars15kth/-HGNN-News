# Hypergraph Bundle Discovery on MIND-Small

## Higher-Order Relational Learning versus Pairwise Transformer Attention

This repository studies whether bundle discovery is better represented as a **higher-order incidence problem** than as a sequence-modelling problem.

The benchmark compares:

[
\text{Hypergraph Neural Network}
\qquad\text{versus}\qquad
\text{Transformer Encoder},
]

on the MIND-Small news recommendation dataset.

The central modelling hypothesis is

[
\boxed{
\text{explicit multi-entity structure}
;>;
\text{implicit pairwise attention}
}
]

when the prediction target depends on groups of mutually related items rather than isolated item-to-item interactions.

The resulting Hypergraph Neural Network improves both hit rate and ranking quality by approximately (38%) over the Transformer baseline.

---

## 1. Problem Formulation

Let

[
V={v_1,\ldots,v_n}
]

denote the set of news items, users, topics, or other recommendation entities.

A conventional graph represents relationships through pairwise edges

[
E\subseteq V\times V.
]

This restricts every interaction to the form

[
v_i \longleftrightarrow v_j.
]

Bundle discovery is generally not pairwise.

A bundle may instead be generated by a relation involving several entities simultaneously:

[
e_\alpha
========

{v_{i_1},v_{i_2},\ldots,v_{i_k}},
\qquad k\geq 2.
]

The appropriate mathematical object is therefore a hypergraph

[
\mathcal H=(V,\mathcal E),
]

where

[
\mathcal E={e_1,\ldots,e_m},
\qquad
e_\alpha\subseteq V.
]

Each hyperedge encodes one higher-order relational unit, such as:

* a user interaction history;
* a co-consumed news bundle;
* a shared semantic or topical context;
* a jointly occurring group of entities;
* a candidate recommendation set.

The learning objective is to infer a scoring map

[
s_\theta:V\times \mathcal C\rightarrow \mathbb R,
]

where (\mathcal C) denotes the observed relational context and

[
s_\theta(v_i\mid \mathcal C)
]

measures the compatibility of item (v_i) with the current bundle state.

The ranked recommendation is

[
\pi_\theta(\mathcal C)
======================

\operatorname{argsort}*{v_i\in V}
s*\theta(v_i\mid\mathcal C).
]

---

## 2. Incidence Representation

The hypergraph is represented by its incidence matrix

[
H\in{0,1}^{n\times m},
]

with

[
H_{i\alpha}
===========

\begin{cases}
1, & v_i\in e_\alpha,\
0, & v_i\notin e_\alpha.
\end{cases}
]

Let

[
W=\operatorname{diag}(w_1,\ldots,w_m)
]

be the hyperedge-weight matrix.

The vertex degree is

[
d(v_i)
======

\sum_{\alpha=1}^{m}
w_\alpha H_{i\alpha},
]

and the hyperedge degree is

[
\delta(e_\alpha)
================

\sum_{i=1}^{n}H_{i\alpha}.
]

Therefore,

[
D_v
===

\operatorname{diag}
\bigl(
d(v_1),\ldots,d(v_n)
\bigr),
]

[
D_e
===

\operatorname{diag}
\bigl(
\delta(e_1),\ldots,\delta(e_m)
\bigr).
]

A normalized hypergraph propagation operator is

[
\mathcal P_{\mathcal H}
=======================

D_v^{-1/2}
HWD_e^{-1}
H^\top
D_v^{-1/2}.
]

This operator performs the transformation

[
\text{vertex}
\rightarrow
\text{hyperedge}
\rightarrow
\text{vertex},
]

so that information is aggregated through shared higher-order structures rather than only through pairwise neighbourhoods.

## 3. Hypergraph Neural Network

Let

[
X^{(0)}\in\mathbb R^{n\times d_0}
]

denote the initial entity-feature matrix.

A hypergraph convolutional layer is defined by

[
X^{(\ell+1)}
============

\sigma
\left(
\mathcal P_{\mathcal H}
X^{(\ell)}
\Theta^{(\ell)}
+
b^{(\ell)}
\right),
]

where:

[
\Theta^{(\ell)}
\in
\mathbb R^{d_\ell\times d_{\ell+1}}
]

is the trainable weight matrix,

[
b^{(\ell)}
\in
\mathbb R^{d_{\ell+1}}
]

is the bias vector, and

[
\sigma(z)=\max(0,z)
]

is the ReLU nonlinearity.

For a two-layer architecture,

[
X^{(1)}
=======

\operatorname{ReLU}
\left(
\mathcal P_{\mathcal H}
X^{(0)}
\Theta^{(0)}
+
b^{(0)}
\right),
]

[
Z_{\mathcal H}
==============

\mathcal P_{\mathcal H}
X^{(1)}
\Theta^{(1)}
+
b^{(1)}.
]

The final matrix

[
Z_{\mathcal H}\in\mathbb R^{n\times d_z}
]

contains higher-order entity embeddings.

A candidate score may then be computed as

[
s_i
===

z_i^\top q,
]

where

[
z_i\in\mathbb R^{d_z}
]

is the embedding of candidate (v_i), and

[
q\in\mathbb R^{d_z}
]

is the representation of the current recommendation context.

Probabilities are obtained through

[
p_i
===

\frac{\exp(s_i)}
{\sum_{j\in\mathcal C}\exp(s_j)}.
]

## 4. Transformer Baseline

The Transformer receives a sequence of item embeddings

[
X=
[x_1,\ldots,x_T]^\top
\in\mathbb R^{T\times d}.
]

For each attention head,

[
Q=XW_Q,
\qquad
K=XW_K,
\qquad
V=XW_V.
]

Scaled dot-product attention is

[
A
=

\operatorname{softmax}
\left(
\frac{QK^\top}{\sqrt{d_k}}
\right),
]

and the resulting representation is

[
Z_{\mathrm{attn}}
=================

AV.
]

Multi-head attention is

[
\operatorname{MHA}(X)
=====================

\operatorname{Concat}
\left(
Z_1,\ldots,Z_h
\right)
W_O.
]

The Transformer learns relational weights of the form

[
A_{ij}
\approx
\text{importance of item }v_j
\text{ to item }v_i.
]

This is fundamentally a pairwise interaction matrix:

[
A\in\mathbb R^{T\times T}.
]

A (k)-entity bundle must therefore be reconstructed indirectly from multiple pairwise coefficients:

[
{v_1,v_2,v_3}
\rightsquigarrow
(A_{12},A_{13},A_{21},A_{23},A_{31},A_{32}).
]

By contrast, a hypergraph represents the same relation directly as

[
e_\alpha={v_1,v_2,v_3}.
]

The representational distinction is therefore

[
\boxed{
\text{Transformer: inferred pairwise composition}
}
]

versus

[
\boxed{
\text{HGNN: explicit higher-order incidence}
}.
]

---

## 5. Structural Comparison

### Transformer relation space

[
\mathcal R_{\mathrm{T}}
\subseteq
V\times V.
]

### Hypergraph relation space

[
\mathcal R_{\mathcal H}
\subseteq
2^V.
]

Since

[
V\times V
\subsetneq
2^V
]

for relations of cardinality greater than two, the hypergraph representation can encode relational structures unavailable as primitive objects in a pairwise graph.

For a bundle

[
B={v_{i_1},\ldots,v_{i_k}},
]

the Transformer approximates its coherence through pairwise decompositions such as

[
\Phi_{\mathrm T}(B)
===================

\sum_{a\neq b}
\alpha_{i_ai_b}.
]

The HGNN represents it through a single incidence object:

[
\Phi_{\mathcal H}(B)
====================

H_{\cdot\alpha},
\qquad
e_\alpha=B.
]

The modelling hypothesis tested in this repository is therefore

[
\mathbb E
\left[
\mathcal L
\left(
\Phi_{\mathcal H}(B)
\right)
\right]
<
\mathbb E
\left[
\mathcal L
\left(
\Phi_{\mathrm T}(B)
\right)
\right].
]

## 6. Learning Objective

Let

[
y_i\in{0,1}
]

denote whether candidate item (v_i) is relevant to the current context.

For binary scoring, the loss is

[
\mathcal L_{\mathrm{BCE}}
=========================

*

\frac{1}{N}
\sum_{i=1}^{N}
\left[
y_i\log p_i
+
(1-y_i)\log(1-p_i)
\right].
]

For candidate-set ranking, the softmax cross-entropy objective is

[
\mathcal L_{\mathrm{rank}}
==========================

*

\frac{1}{M}
\sum_{u=1}^{M}
\log
\frac{
\exp(s_{u,+})
}{
\exp(s_{u,+})
+
\sum_{j\in\mathcal N_u}
\exp(s_{u,j})
},
]

where:

[
s_{u,+}
]

is the positive-item score for context (u), and

[
\mathcal N_u
]

is its negative-candidate set.

A regularized objective may be written as

[
\mathcal J(\theta)
==================

\mathcal L_{\mathrm{rank}}
+
\lambda
|\theta|_2^2.
]

## 10. Ranking Metrics

### Hit Rate at (K)

For user (u),

[
\operatorname{HR@K}_u
=====================

\mathbf 1
\left[
\operatorname{rank}_u(v_u^+)
\leq K
\right].
]

The mean hit rate is

[
\operatorname{HR@K}
===================

\frac{1}{M}
\sum_{u=1}^{M}
\operatorname{HR@K}_u.
]

It measures whether the relevant item appears anywhere in the first (K) ranked outputs.

---

### Normalized Discounted Cumulative Gain

For binary relevance,

[
\operatorname{DCG@K}_u
======================

\sum_{r=1}^{K}
\frac{
2^{\operatorname{rel}_{u,r}}-1
}{
\log_2(r+1)
}.
]

The normalized score is

[
\operatorname{NDCG@K}_u
=======================

\frac{
\operatorname{DCG@K}_u
}{
\operatorname{IDCG@K}_u
}.
]

The dataset-level metric is

[
\operatorname{NDCG@K}
=====================

\frac{1}{M}
\sum_{u=1}^{M}
\operatorname{NDCG@K}_u.
]

Unlike HR@10, NDCG@10 rewards the model for assigning the relevant item a higher position within the recommendation list.

The joint improvement

[
\operatorname{HR@10}_{\mathcal H}

>

\operatorname{HR@10}_{\mathrm T}
]

and

[
\operatorname{NDCG@10}_{\mathcal H}

>

\operatorname{NDCG@10}_{\mathrm T}
]

shows that the HGNN improves both:

[
\text{candidate recovery}
]

and

[
\text{ranking order}.
]

## 11. Popularity-Segment Evaluation

Let item popularity be

[
\rho(v_i)
=========

\sum_{u}
\mathbf 1
[
v_i\in \mathcal H_u
].
]

Items may be partitioned into popularity strata

[
V
=

V_{\mathrm{head}}
\sqcup
V_{\mathrm{mid}}
\sqcup
V_{\mathrm{tail}}.
]

The corresponding segment-level metric is

[
m_s
===

m
\left(
{v_i:v_i\in V_s}
\right),
\qquad
s\in
{
\mathrm{head},
\mathrm{mid},
\mathrm{tail}
}.
]

This evaluation tests whether the model learns genuine relational structure or merely exploits marginal item frequency.

A popularity-only scoring rule has the form

[
s_{\mathrm{pop}}(v_i)
\propto
\rho(v_i).
]

A structural model instead seeks

[
s_{\mathrm{struct}}(v_i\mid \mathcal H_u)
\not\equiv
f(\rho(v_i)).
]

The hypergraph formulation is particularly relevant to sparse and tail entities because an item can inherit information through shared hyperedges even when its direct interaction count is limited.

## 12. Why the HGNN Performs Better

The empirical result can be interpreted through three mathematical properties.

### 12.1 Higher-Order Closure

For a hyperedge

[
e_\alpha
========

{v_1,\ldots,v_k},
]

the HGNN propagates information jointly across all members:

[
x_i'
\propto
\sum_{\alpha:v_i\in e_\alpha}
\frac{w_\alpha}{\delta(e_\alpha)}
\sum_{j:v_j\in e_\alpha}
x_j.
]

The update is conditioned on common group membership, not merely on independently learned pairwise similarities.

---

### 12.2 Structured Inductive Bias

The model does not need to infer whether a higher-order relation exists.

That relation is already encoded in

[
H_{i\alpha}.
]

Consequently, the learning problem changes from

[
\text{discover relation}
+
\text{learn prediction}
]

to

[
\text{propagate over relation}
+
\text{learn prediction}.
]

This reduces the burden placed on the trainable parameters.

---

### 12.3 Relational Parameter Efficiency

A bundle of size (k) produces

[
O(k^2)
]

pairwise interactions under self-attention.

In the incidence representation, the same bundle is encoded by

[
O(k)
]

non-zero memberships in one hyperedge column.

Therefore,

[
\text{pairwise encoding complexity}
\sim
k^2,
]

while

[
\text{incidence encoding complexity}
\sim
k.
]

This does not imply that every HGNN implementation is computationally cheaper than every Transformer. It means that the underlying higher-order relation is represented more directly.

Although evaluated on news recommendation, the mathematical structure is domain-independent.

Let

[
V
=

\text{entities}
]

and

[
\mathcal E
==========

\text{multi-entity relations}.
]

The same architecture can represent:

[
\text{users}
+
\text{devices}
+
\text{accounts}
+
\text{network infrastructure}
+
\text{events},
]

with hyperedges corresponding to:

[
\text{shared sessions},
]

[
\text{coordinated activity},
]

[
\text{common infrastructure},
]

[
\text{campaign membership},
]

or

[
\text{multi-stage behavioural patterns}.
]

In cybersecurity, a coordinated pattern may be written as

[
e_\alpha
========

{
\text{account},
\text{device},
\text{IP address},
\text{domain},
\text{process},
\text{event}
}.
]

A pairwise reduction separates this object into many edges:

[
(\text{account},\text{device}),
\quad
(\text{device},\text{IP}),
\quad
(\text{IP},\text{domain}),
\quad \ldots
]

The hypergraph preserves the complete relation as one structured unit.

Therefore, the benchmark supports the broader principle

[
\boxed{
\text{coordinated multi-entity behaviour}

\text{higher-order relational learning}
}.
]
